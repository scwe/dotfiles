# Global Preferences

## PR bodies and commit extended messages

Write succinctly, in simple personable language. Focus on the *why*, not the *what* — the diff already shows what changed.

- Lead with motivation: the problem, the constraint, the reason for this approach.
- Skip bullet-by-bullet change lists unless a reviewer genuinely can't find them.
- Write like a person talking to a teammate, not a changelog generator.
